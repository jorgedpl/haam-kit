# changes

Un petit fichier par modification livrée, nommé `<FILE-ID>.md` (par exemple `GH-12.md`), ajouté par `/uat` sur la branche propre à la modification, pour qu'il soit livré avec elle. Un fichier par modification, cela veut dire que des PR en parallèle n'entrent jamais en conflit ici.

Chaque fichier tient en une ou deux lignes qu'un utilisateur comprendrait :

```
- #12: Export to CSV now works on mobile.
```

Pour rédiger des notes de version ou mettre à jour `CHANGELOG.md`, demandez à un agent de rassembler les fichiers ajoutés depuis la dernière release.
