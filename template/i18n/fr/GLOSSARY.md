# Glossaire de traduction (français)

Ce tableau fixe la façon dont les termes clés de HAAM sont rendus en français, pour que les traductions restent cohérentes d'une modification à l'autre.

**Conventions générales**
- Le lecteur est vouvoyé (« vous »), partout. Les exemples de phrases adressées à un agent utilisent aussi « vous ».
- Typographie : une espace simple avant `:` `;` `?` `!` et à l'intérieur des guillemets français « … ». Jamais dans le code.
- Le code, les commandes, les labels, les statuts, les noms de paramètres et les chemins restent en anglais, entre backticks, sans modification.
- Les noms de statut du tableau (Triage, Discovery, Decision, Backlog, Ready, In Progress, In Review, UAT, Deploying, Done, Parked, Canceled) et les labels (epic, bug…) restent en anglais, même sans backticks. Les portes gardent leurs noms G1–G5.
- Formulations épicènes quand c'est naturel (personne, membre de l'équipe, responsable, admin) ; sinon masculin générique, sans barre oblique ni point médian.
