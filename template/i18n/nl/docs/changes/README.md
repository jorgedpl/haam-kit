# changes

Eén klein bestand per wijziging die live gaat, met de naam `<FILE-ID>.md` (bijv. `GH-12.md`), toegevoegd door `/uat` op de eigen branch van de wijziging, zodat het met de wijziging meegaat. Eén bestand per wijziging betekent dat parallelle PR's hier nooit conflicteren.

Elk bestand bestaat uit een of twee regels die een gebruiker zou begrijpen:

```
- #12: Export to CSV now works on mobile.
```

Om release notes te schrijven of `CHANGELOG.md` bij te werken, vraag je een agent om de bestanden te verzamelen die sinds de laatste release zijn toegevoegd.
